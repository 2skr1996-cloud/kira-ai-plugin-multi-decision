一个给 KiraAI 用的聊天插件。它接管群聊的触发判定与上下文窗口：这一条要不要回、等多久回、上下文留多少，从框架里写死的一段逻辑变成一页自己能调的设置；同一个人连发几句会先攒着合成一条再回；每一次判定、每一次请求、每一轮裁切都落盘，出问题时能一条条点开看。

> [!WARNING]
> **A3.0.3（Alpha 测试版），可能有不少 BUG。**
>
> - **没和任何别的插件一起测过。** 同时装别的聊天 / 上下文类插件会怎样，作者不知道；建议先单独跑一段看看。
> - 私聊场景、以及部分功能没有经过充分测试，出问题别意外。
> - 代码主要由 DeepSeek、GPT 辅助完成，作者是使用者不是专业开发者，review 得不算严。
> - 遇到怪现象，先去「缓存记录 → 请求快照」里翻那一轮的实际入参，多半能看出原因。
> - 欢迎开 issue，附上请求快照里能说明问题的那一段（记得自己先抹掉隐私）。

## 它解决什么问题

- 默认的掷骰子太粗糙：要么一句话都不回，要么逮着一句就回。这里可以按条数、按概率、按一天里的时段来定，还能让一个便宜的模型先看一眼再决定。
- 上下文窗口看不懂也改不动：留多少条、什么时候裁、裁掉哪一段，这里全在设置页上。
- 出了问题没法复盘：每一次判定、每一次请求、每一轮裁切都留了快照，网页上能一条条点开。

## 功能清单

**判定**

| | 项目 | 说明 |
| --- | --- | --- |
| ✅ | 四档判定 | 计数 / 概率 / 时段曲线 / 进阶模式，一个入口随时切 |
| ✅ | 进阶模式 | 先让便宜模型读一遍实时窗判「回不回」，判回才跑完整一轮 |
| ✅ | 节奏排队 | 越等越容易中，长期平均不变，不是每轮独立掷骰 |
| ✅ | 决策注记 | 每次判定写一句话进窗口，模型知道自己刚为什么回或不回 |
| ✅ | 决策模型容错 | 失败重试、切备用模型、冷却切回；彻底失败按设置放行或拦下 |

**触发与时机**

| | 项目 | 说明 |
| --- | --- | --- |
| ✅ | 触发与必回 | 艾特 / 名字 / 外号三路，各有「算触发」「直接回」两个开关 |
| ✅ | 休息时段 | 单独一套概率；睡着被叫时理不理另有两个开关 |
| ✅ | 防抖合并 | 同一个人连发几句先攒着，合成一条再回 |
| ✅ | 抖动等待 | 命中后随机等一会儿再发，不秒回 |
| ✅ | 短语过滤 | 整条等于黑名单短语的不算一次触发 |

| | 项目 | 说明 |

| ✅ | 单群覆盖 | 每个群一套独立设置，没单独设的跟全局走 |

## 安装

1. 把整个文件夹放进 KiraAI 的 `data/plugins/` 下，目录名保持 `kira-ai-plugin-multi-decision`。
2. 在 KiraAI 的插件页启用「多样决策」。启用即接管内置的 default-chat：原来那个掷骰子判定不再生效（不接管会两边各自攒消息、重复回）。
3. 打开插件页面，按需要改设置。默认值就是能直接跑的一套。
4. 想换回原来的样子：把「聊天决策」的总开关关掉，或停用本插件，default-chat 会被自动放开。升级就直接覆盖插件目录，plugin_data 里的数据不动。

没有第三方依赖，Python 3.11+ 即可。

## 界面在哪

插件页顶部有「首页 / 设置」两个按钮。

- 首页：三个页签——当前窗口 / 回复记录 / 决策记录。
- 设置：六个页签——基础设置 / 聊天决策 / 窗口设置 / 提示词 / 缓存记录 / API 价目。

## 数据放在哪

全部落在 `data/plugin_data/kira-ai-plugin-multi-decision/`：

- `requests/`：每轮的请求快照（含实际发出的 system 与本轮消息），排查问题主要看这里。
- `data/`：窗口状态、判定日志、图片缓存索引、调参记录。
- `media/`：图片缓存本体。
- `stats/`：会话统计。

删插件目录不会删这些；要清掉请在「缓存记录」页按类别清，或手动删 `plugin_data` 下对应目录。

## 设置

设置页面基本都能改：判定方式、触发与必回、休息时段、窗口条数、裁切时机、图片缓存上限、API 单价都在页面上；提示词的两套布局也在设置页里排，模块可以增删、上下移、停用，右栏实时预览拼好的结果。
