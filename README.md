这是一个给 KiraAI 用的聊天插件，主要解决两件事：决定机器人什么时候回复，以及决定它记住哪些聊天内容。它主要面向群聊；私聊目前可以运行，但测试较少。启用后会接管 KiraAI 的 `default-chat`，避免两个决策器同时攒消息、重复回复；停用插件或关闭“聊天决策”总开关后，可以恢复默认聊天。

它还会把同一个人连续发送的几句话先攒起来再处理，并把每次判定、请求和裁切记录下来，方便排查问题。

> [!WARNING]
> **A3.0.6（Alpha 测试版），可能有不少 BUG。**
>
> - **没和任何别的插件一起测过。** 同时装别的聊天 / 上下文类插件会怎样，作者不知道；建议先单独跑一段看看。
> - 私聊场景、以及部分功能没有经过充分测试，出问题别意外。
> - 代码主要由 DeepSeek、GPT 辅助完成，作者是使用者不是专业开发者，review 得不算严。
> - 遇到怪现象，先去「缓存记录 → 请求快照」里翻那一轮的实际入参，多半能看出原因。
> - 请求快照可能包含聊天内容、系统提示词或其他敏感信息；提交 issue 或截图前请先脱敏。
> - 欢迎开 issue；如果附请求快照，只提供能说明问题的必要部分。

## 它解决什么问题

- 默认的掷骰子太粗糙：要么一句话都不回，要么逮着一句就回。这里可以按条数、按概率、按一天里的时段来定，还能让一个便宜的模型先看一眼再决定。
- 上下文窗口看不懂也改不动：留多少条、什么时候裁、裁掉哪一段，这里全在设置页上。
- 出了问题没法复盘：每一次判定、每一次请求、每一轮裁切都留了快照，网页上能一条条点开。

## 安装

1. 把整个文件夹放进 KiraAI 的 `data/plugins/` 下，目录名保持 `kira-ai-plugin-multi-decision`。
2. 在 KiraAI 的插件页启用「多样决策」。启用即接管内置的 default-chat：原来那个掷骰子判定不再生效（不接管会两边各自攒消息、重复回）。
3. 打开插件页面，按需要改设置。默认值就是能直接跑的一套。
4. 想换回原来的样子：把「聊天决策」的总开关关掉，或停用本插件，default-chat 会被自动放开。升级时可直接覆盖插件目录；`plugin_data` 里的数据不会被插件目录覆盖，但仍建议先备份重要记录。

没有第三方依赖，Python 3.11+ 即可。

## 第一次使用

1. 安装插件并启用「多样决策」。
2. 先保持默认设置，发几条消息观察。
3. 如果没有回复，先看「决策记录」，再看「缓存记录 → 请求快照」。
4. 确认稳定后，再一次只改一项设置。

## 界面在哪

插件页顶部有「首页 / 设置」两个按钮。

- 首页：三个页签——当前窗口 / 回复记录 / 决策记录。
- 设置：六个页签——基础设置 / 聊天决策 / 窗口设置 / 提示词 / 缓存记录 / API 价目。

## 数据放在哪

全部落在 `data/plugin_data/kira-ai-plugin-multi-decision/`：

- `requests/`：每轮的请求快照（含实际发出的 system 与本轮消息），排查问题主要看这里。
- `data/`：窗口状态、判定日志、图片缓存索引、调参记录。
- `media/`：图片缓存本体。
- `stats/`：会话统计。

删插件目录不会删这些；要清掉请在「缓存记录」页按类别清，或手动删 `plugin_data` 下对应目录。请求快照和图片缓存可能占用磁盘空间，也可能包含聊天内容、提示词或其他敏感信息。

## 设置

设置页面基本都能改：判定方式、触发与必回、休息时段、窗口条数、裁切时机、图片缓存上限都在页面上；“API 价目”用于插件内的费用统计或估算，不是替你管理或支付账单。提示词的两套布局也能在设置页里排，模块可以增删、上下移、停用，右栏会预览拼好的结果。

## 常见问题

- **为什么会重复回复？** 确认没有同时让本插件和 `default-chat` 接管聊天。
- **为什么没有回复？** 先看「决策记录」，再看「缓存记录 → 请求快照」，并检查配额、休息时段和过滤设置。
- **怎样恢复默认聊天？** 关闭「聊天决策」总开关，或停用本插件。
- **怎样清理数据？** 使用「缓存记录」页按类别清理，或删除 `plugin_data` 下对应目录。
