# 默认设置

插件自己的设置项一共 94 项，键名与出厂默认值如下。绝大多数能在插件的设置页里直接改；设置页没放出来的项，可以改 data/config/plugins/kira-ai-plugin-multi-decision.json（保存后热重载）。

| 键 | 名称 | 默认 | 说明 |
| --- | --- | --- | --- |
| `enabled` | 启用插件 | 开 | 总开关。关闭后插件完全静默。 |
| `decision_enabled` | 接管群聊触发判定 | 开 | 决定消息要不要回，并停用内置 default-chat。 |
| `trigger_mode` | 触发模式 | count | count 攒够条数；probability 按概率；adaptive 按曲线每段自动调概率。 |
| `trigger_threshold` | 计数触发 | 5 | 每 N 条回一次 |
| `trigger_probability` | 触发概率 | 20 | 按概率回 |
| `prob_pseudo` | 节奏模式 | 关 | 开 = 按节奏排队，越等越容易中；关 = 每条单独掷骰。 |
| `advanced_enabled` | 开启进阶模式 | 关 | 打开后先单独判这轮回不回，判要回才走完整回复。 |
| `reply_seg_overrides` | 回复提示词分段改写 | （空） | 设置页「回复提示词」左栏改过的段，JSON。留空 = 全部用框架原文。 |
| `decision_tools` | 决策可用工具 | （空） | 勾选后写进决策提示词，也作为原生工具一起发。 |
| `decision_tool_rounds` | 工具最多几轮 | 2 | 决策模型调工具最多来回几次。 |
| `decision_model` | 决策模型 | （空） | 留空 = 用框架的快速模型。 |
| `decision_fallback_model` | 备用模型 | （空） | 主模型连续失败后切它；留空 = 不切。 |
| `decision_retry` | 重试次数 | 2 | 主模型失败后原地重试几次。 |
| `decision_retry_delay` | 重试间隔 | 3 | 两次重试之间等几秒。 |
| `decision_fail_switch` | 连续失败切换 | 2 | 主模型连续失败几次才切备用模型。 |
| `decision_fallback_cooldown` | 切回主模型等待 | 300 | 切到备用后过多少秒再试主模型。 |
| `decision_timeout` | 单次超时 | 60 | 一次决策最多等几秒，超时算失败。 |
| `decision_see_images` | 决策看图 | 开 | 决策模型也看一眼这一轮消息里的图片。它本身得是能看图的模型；万一上游不认图，会自动退回纯文字再判一次。 |
| `decision_fail_action` | 决策失败时 | allow | allow = 照常回复，block = 这轮不回。 |
| `adaptive_step` | 每轮最多调几个点 | 2 | 每轮最多挪几个百分点。 |
| `adaptive_tune_minutes` | 调参间隔 | 10 | 隔多久重新算一次这段该用多少概率。越小跟得越快，也越容易被一天的波动带偏。 |
| `adaptive_rhythm_sigma` | 节奏松紧 | 65 | 回消息的节奏要多不固定：0 = 每隔固定条数回（像按时刻表），65 = 正常，偶尔早、最晚等 1.5 倍，120 = 很随意，最晚等 2 倍。只改手感，平均多久回一次不变。 |
| `stats_window_days` | 数据使用 | 7 | 每段平均按最近几天算，最少 7 天。 |
| `adaptive_weekday_bucket` | 使用星期数据 | 关 | 按同一个星期几比；不足 4 周退回最近 7 天。 |
| `bands_enabled` | 启用时段曲线 | 关 | 开着就按当前时段的概率决定回不回，普通模式那列变灰。 |
| `time_bands` | 时段曲线 | [{"s": 0, "e": 24, "v": 20}, {"s": 24, "… | 一天切 48 格（每格半小时），每段一个概率；点段右上角的月亮，那段就是休息时段。 |
| `nicknames` | 机器人外号 | （空） | 群友叫 bot 的其它称呼，可加多条。 |
| `nickname_wake` | 外号触发唤醒 | 开 | 开启后喊外号直接进判断，不看计数。 |
| `name_wake` | 昵称触发唤醒 | 开 | 开启后喊机器人名字直接进判断，不看计数。 |
| `mention_always_reply` | 艾特必回 | 关 | 被 @ 时跳过模型判断直接回（开启进阶模式后与「艾特触发」的区别才看得出来）。 |
| `mention_trigger` | 艾特触发 | 开 | 被 @ 时直接算一次触发，不攒条数。 |
| `nickname_wake_always_reply` | 外号必回 | 关 | 被喊外号时跳过模型判断直接回。 |
| `name_wake_always_reply` | 昵称必回 | 关 | 被喊名字时跳过模型判断直接回。 |
| `rest_wake_trigger` | 休息时段·触发 | 开 | 休息时段里被艾特 / 喊外号 / 喊名字，还算一次触发。关掉＝睡觉时被叫也不理。 |
| `rest_wake_always` | 休息时段·必回 | 关 | 休息时段里被叫到时，上面那几个「必回」照样生效。默认关＝睡觉时必回也不叫醒。 |
| `jitter_enabled` | 抖动 | 关 | 开启后，新消息触发后先等一会儿再动，把这几秒里的话攒到一起看。 |
| `jitter_seconds` | 抖动等待秒数 | 7 | 固定等这么多秒再动。这期间又攒够一次触发，就再叠一档（7 → 14 → 21），最多叠到下面「防抖上限轮次」那么多档——群里一直有人说话时，这一轮最多等这么久。 |
| `jitter_max_rounds` | 防抖上限轮次 | 3 | 最多叠几次。设 3 就是最多 7+7+7（秒数按上面那个），到顶就不再往后拖了。 |
| `jitter_skip_must_go` | 必回不等防抖 | 开 | 被 @ 或被叫名字时直接开跑，不等防抖那几秒。关掉＝被点名也照样等完防抖再动。 |
| `burst_merge_enabled` | 连发合并 | 关 | 同一个人连着发好几条时只算一条消息。 |
| `burst_merge_seconds` | 连发合并秒数 | 15 | 这段时间内同一人的连发只算 1 条消息。 |
| `phrase_filter_enabled` | 短语黑名单 | 开 | 在清单中的短语不会触发判定。 |
| `phrase_filter_list` | 短语黑名单清单 | ["哈哈","草"] | 一行一条；前后标点和空格会被忽略。 |
| `silent_trigger_enabled` | 静默兜底 | 开 | 聊天安静后，如果还有没处理的消息就补一次；休息时段不生效。 |
| `silent_trigger_minutes` | 兜底等待分钟 | 3 | 群安静这么多分钟后补处理一次。 |
| `rest_mode_enabled` | 休息时段 | 开 | 普通模式用；这段时间只按下面的概率掷骰。 |
| `rest_start` | 休息开始 | 23:00 | 半小时一档，从下拉里选。 |
| `rest_end` | 休息结束 | 08:00 | 半小时一档，可跨零点。 |
| `rest_probability` | 休息时段回复概率 | 2 | 休息时只按这个概率掷骰。 |
| `rest_silent_enabled` | 休息时段兜底 | 关 | 休息时段里也允许闲时兜底补一次。 |
| `rest_silent_minutes` | 休息兜底等待分钟 | 3 | 休息时段里安静这么多分钟后补一次。 |
| `quota_hour_enabled` | 每小时配额 | 关 | 按小时封顶：每小时最多回几次，关掉不限。 |
| `quota_max_per_hour` | 每小时最多回复 | 10 | 每小时最多回几次；@ 与叫名字直达也算。 |
| `quota_day_enabled` | 每天配额 | 关 | 按天封顶：每天最多回几次，0 点清零。 |
| `quota_max_per_day` | 每天最多回复 | 100 | 每天最多回几次；@ 与叫名字直达也算。 |
| `backoff_enabled` | 连续不回后退避 | 关 | 连续不回时拉长下一次阈值，避免硬凑。这一项目前还在灰度：界面上是灰的，判定链路已经接好，等验证完再开放。 |
| `backoff_start_rejects` | 退避起始次数 | 2 | 连续多少次不回后开始退避。 |
| `backoff_base_seconds` | 退避基准秒数 | 15 | 首次退避秒数，之后指数增长。 |
| `backoff_max_seconds` | 退避封顶秒数 | 300 | 退避等待上限。 |
| `backoff_bypass_count` | 积压绕过条数 | 6 | 积压到这么多条时无视退避立即触发。 |
| `window_keep` | 裁切后保留条数 | 30 | 裁切后窗口里只留最近这么多条消息（用户和 bot 一起算）。 |
| `window_buffer` | 裁切缓冲条数 | 10 | 一直没触发请求时，窗口攒到「保留条数 + 缓冲」条就强制裁一次，别让上下文无限长。 |
| `history_images` | 历史里保留几张原图 | 128 | 历史只留最近这么多张原图，更早换成 [图片]；0 = 全换。 |
| `window_trim_threshold` | 裁切触发阈值 | 60 | 用户消息攒够这么多条才裁一次，攒够一倍再动刀更省缓存。 |
| `protect_tool_groups` | 保护工具调用组 | 开 | 裁切点避开工具调用配对，建议保持开启。 |
| `summary_enabled` | 启用中期摘要 | 关 | 把裁掉的消息压成摘要放窗口顶部，纯机械，默认关。 |
| `summary_max_chars` | 中期摘要字数上限 | 300 | 摘要总字数上限，超了从最旧丢起。 |
| `summary_line_chars` | 摘要每条压多少字 | 40 | 每条消息压成摘要行保留多少字。 |
| `media_cache_limit` | 图片缓存上限（每个群组） | 2000 | 每个群组各自保留的上限；整个目录最多＝这个值 × 群组数量。超了从最旧的删；2 小时内新收的先不动（用户 m06046 图2：刚决策完的图不该被裁掉）。 |
| `media_cache_limit_dm` | 图片缓存上限（私聊） | 200 | 每个私聊最多留多少张图，超了从最旧的删。 |
| `media_cache_keep_days` | 缓存保留天数 | 56 | 超过这么多天的图片自动删掉，0 = 不限。 |
| `bot_qq` | 机器人 QQ 号 | （空） | 已自动从框架读取，无需填写。 |
| `bot_name` | 机器人昵称 | （空） | bot 在历史里的显示名，留空取适配器昵称。 |
| `admin_name` | 管理员名字 | （空） | QQ 里的真实名字，不是群昵称。 |
| `admin_id` | 管理员 QQ 号 | （空） | 填 QQ 号即可。 |
| `admin_list` | 管理员名单 | （空） | 这一行同时管管理员的名字与 QQ 号：第一行填名字，第二行填 QQ 号，可以加多位。 |
| `trace_keep` | 回复快照上限（群聊） | 100 | 每个群最多留多少份回复快照，一份带一次回复的完整轨迹。 |
| `trace_keep_dm` | 回复快照上限（私聊） | 50 | 每个私聊最多留多少份回复快照。 |
| `requests_keep_days` | 快照保留天数 | 56 | 超过这么多天的回复快照和决策快照自动删掉，0 = 不限。 |
| `decision_keep` | 决策快照上限（群聊） | 100 | 每个群最多留多少份决策快照，一份是决策模型这一轮读到的全部内容和它的判断。 |
| `decision_keep_dm` | 决策快照上限（私聊） | 50 | 每个私聊最多留多少份决策快照。 |
| `decisions_keep_days` | 消息日志保留天数 | 56 | 最少 56 天，只能调高——自适应要用这段时间的数据。 |
| `windows_keep_days` | 窗口快照保留天数 | 56 | 超过这么多天的窗口快照自动删掉。 |
| `windows_keep` | 窗口快照上限（群聊） | 300 | 每个群最多留多少份窗口快照（回复轮和决策轮各记一份），0 = 不限。 |
| `windows_keep_dm` | 窗口快照上限（私聊） | 60 | 每个私聊最多留多少份窗口快照，0 = 不限。 |
| `summaries_keep` | 中期摘要上限（群聊） | 0 | 最多留多少个群的摘要，0 = 不限。 |
| `summaries_keep_dm` | 中期摘要上限（私聊） | 0 | 最多留多少个私聊的摘要，0 = 不限。 |
| `summaries_keep_days` | 中期摘要保留天数 | 56 | 摘要留多久自动删，0 = 不限。 |
| `stats_keep_days` | 会话统计保留天数 | 56 | 最少 56 天，只能调高——自适应要用这段时间的数据。 |
| `retry_max` | 自动重试次数 | 2 | 出错后自动重试，0 = 不重试。 |
| `retry_delay` | 重试间隔秒数 | 5 | 每次重试前等几秒。 |
| `watchdog_seconds` | 看门狗超时 | 180 | 请求多少秒后还没等到回复，就强制停止，并走重试流程。可设 30-600 秒。 |
| `band_rest_probability` | 休息回复概率 | 2 | 点了月亮的段，按这个概率掷骰。 |
| `adaptive_weekday_window_weeks` | 用几周 | 8 | 最少 4 周。 |
