# 多样决策插件 · 全部默认设置

共 **104** 项。分两部分：**A. 设置页上能直接改的（42 项）**、**B. 页面上看不到、只在配置文件里的（62 项）**。

> 默认值＝插件第一次装上、或点了「恢复默认」之后的值。界面上的开关显示为「开 / 关」。

---

## A. 设置页上能改的

### 基础设置

**身份**

| 设置项 | 键 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- | --- |
| 机器人昵称 | `bot_name` | 文本 | （空） | bot 在历史里的显示名，留空取适配器昵称。 |
| 机器人外号 | `nicknames` | 多选 | [] | 群友叫 bot 的其它称呼，可加多条。 |
| 管理员名单 | `admin_list` | 文本 | （空） | 这一行同时管管理员的名字与 QQ 号：第一行填名字，第二行填 QQ 号，可以加多位。 |
| 看门狗超时 | `watchdog_seconds` | 数字 | 180 | 请求多少秒后还没等到回复，就强制停止，并走重试流程。可设 30-600 秒。 |
| 自动重试次数 | `retry_max` | 数字 | 2 | 出错后自动重试，0 = 不重试。 |
| 重试间隔秒数 | `retry_delay` | 数字 | 5 | 每次重试前等几秒。 |
| 接管群聊触发判定 | `decision_enabled` | 开关 | 开 | 决定消息要不要回，并停用内置 default-chat。 |
| 艾特触发 | `mention_trigger` | 开关 | 开 | 被 @ 时直接算一次触发，不攒条数。 |
| 外号触发唤醒 | `nickname_wake` | 开关 | 开 | 开启后喊外号直接进判断，不看计数。 |
| 昵称触发唤醒 | `name_wake` | 开关 | 开 | 开启后喊机器人名字直接进判断，不看计数。 |
| 休息时段·触发 | `rest_wake_trigger` | 开关 | 开 | 休息时段里被艾特 / 喊外号 / 喊名字，还算一次触发。关掉＝睡觉时被叫也不理。 |
| 每小时配额 | `quota_hour_enabled` | 开关 | 关 | 按小时封顶：每小时最多回几次，关掉不限。 |
| 每天配额 | `quota_day_enabled` | 开关 | 关 | 按天封顶：每天最多回几次，0 点清零。 |
